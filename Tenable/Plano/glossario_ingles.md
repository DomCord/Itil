# Glossário para leitura da prova

| Inglês | Português ou sentido no estudo |
|---|---|
| Host discovery | Descoberta de hosts |
| Credentialed scan | Scan autenticado |
| Unauthenticated scan | Scan sem credenciais |
| Finding | Ocorrência de uma vulnerabilidade ou resultado |
| Asset | Ativo |
| Reachability | Capacidade de alcançar o alvo |
| Plugin family | Família de plugins |
| Linking key | Chave de vínculo inicial do sensor |
| Scan window | Janela de participação do agent scan |
| Triggered scan | Scan iniciado por trigger do agent |
| Recast | Ajuste da severidade por regra |
| Accept risk | Aceitação de risco |
| Resurfaced | Detectada novamente após Fixed |
| Privilege escalation | Elevação de privilégios |
| Administrative share | Compartilhamento administrativo |
| Audit file | Arquivo de verificações de configuração |
| Benchmark | Conjunto de requisitos de configuração |
| Warning | Resultado que exige análise ou revisão |
| Drill-down | Acesso aos dados que compõem uma visão agregada |
| Scope | Escopo |
| Target | Alvo |
| Least privilege | Privilégio necessário à função |
| VPR | Vulnerability Priority Rating |
| ACR | Asset Criticality Rating |
| SLA | Service-Level Agreement |
| Except / NOT | Exceto / NÃO |
| Most appropriate / best | Mais adequado ao cenário |
| Always / never / only | Sempre / nunca / somente. Conferir absolutos |
| First / next | Primeiro / próximo. Conferir a etapa de diagnóstico |
