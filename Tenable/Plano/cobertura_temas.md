# Mapa didático dos domínios

Base: domínios amplos F01 e ementa F02. A correspondência é uma organização de estudo. Não se presume distribuição oficial de questões por módulo.

| Tema | Domínios relacionados | Competência |
|---|---|---|
| 01 Arquitetura e fundamentos | Installation, Configuration | Escolher os sensores e planejar uma implantação com cobertura verificável. |
| 02 Instalação e sensores | Installation | Vincular sensores, distinguir interfaces e diagnosticar falhas de comunicação. |
| 03 Configuração e acesso | Configuration | Organizar ativos, aplicar acesso adequado e controlar o escopo dos scans. |
| 04 Host Discovery e inventário | Host Discovery | Encontrar hosts, verificar a cobertura e interpretar as limitações da descoberta. |
| 05 Scans de rede e credenciais | Vulnerability Assessment, Configuration | Configurar avaliação de rede e comprovar a execução das verificações autenticadas. |
| 06 Agents e cobertura móvel | Installation, Vulnerability Assessment | Escolher a modalidade de scan de agents e interpretar vínculo, execução e envio. |
| 07 Findings, risco e exceções | Vulnerability Assessment, Configuration | Interpretar achados e justificar prioridades e exceções com evidências. |
| 08 Compliance, relatórios e resposta | Vulnerability Assessment, Configuration | Interpretar audits e comunicar correção com dados rastreáveis. |
